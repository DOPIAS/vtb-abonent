# Демонстрационные данные

Явная команда из `apps/api`: `go run ./cmd/seed` (после миграций, с `DATABASE_URL`).

Создаёт синтетическую учётную запись `demo@abonent.local` / `DemoPass123!`, клиента и оплаченный пакет: 8 занятий, 5 проведено, 3 осталось. Добавляет 3 запланированных занятия и выводит личную ссылку.

Сервер никогда не запускает seed автоматически. Повторный запуск использует существующий демонстрационный пакет и сохраняет его изменения; клиентская ссылка ротируется. Команда предназначена только для разработки.

`go run ./cmd/seed --showcase` создаёт отдельную синтетическую учётную запись `showcase@abonent.local` / `DemoPass123!` и трёх клиентов: оплаченный пакет 8/5/3 за 16 000 ₽, пакет 2/1/1 за 4 000 ₽ для сценария продления, ожидающий оплату пакет 4/0/0 за 8 000 ₽. Непроведённые занятия назначены на будущие дни. Обычный demo и существующие пользовательские данные не меняются. Повторный запуск сохраняет изменения, включая даты и статусы, и ротирует ссылку основного пакета. Это учебные данные без банковской интеграции.
