# Клиент «Абонент»

Expo Router + React Native Web, одна кодовая база для преподавателя и публичной страницы `/s/:token`. Все данные загружаются из Go API. Для опубликованного web build используйте `EXPO_PUBLIC_API_URL=/api/v1`, для разработки `http://localhost:8080/api/v1`, для физического телефона — доступный с него LAN/HTTPS адрес API.

```sh
npm ci
cp .env.example .env.local
npx expo start
npm run typecheck
npm run lint
npm test
npx expo-doctor
npm run export:web
```

`web.output` явно установлен в `single`: хостинг обязан отдавать `dist/index.html` для вложенных маршрутов (корневой Caddyfile это обеспечивает). `EXPO_PUBLIC_API_URL` встраивается во время экспорта: после изменения пересоберите web. Публичная страница не требует входа, обновляет данные каждые 15 секунд и при возвращении фокуса. Ссылка предназначена для просмотра; храните и передавайте её как личную.

Веб-сессия преподавателя хранится в `sessionStorage` текущей вкладки, на Android/iOS — `expo-secure-store`. Пароли не сохраняются. Копирование через `expo-clipboard` доступно в Expo Go. При запрете буфера обмена можно выделить текст ссылки вручную. Значимые действия подтверждаются кроссплатформенным RN Modal, работающим в браузере.

Дата выбирается в календаре, время — отдельными контролами в 24-часовом формате. В браузере доступны переходы по месяцам/годам, «Сегодня» и «Завтра»; на телефоне открывается системный выбор даты/времени. Отмена системного диалога не меняет выбор. Локальное время устройства отправляется в API как ISO UTC. Стоимость вводится в рублях и отправляется целым числом копеек. Оплаченные, проведённые и оставшиеся занятия отображаются из ответа сервера.

Выбран Expo SDK 58: `expo install` подбирает React, React Native, Router и Expo modules по карте совместимости. Resolver 5.9.2 совместим с Zod 4 и RHF 7; resolver 6.0.0 имеет конфликт optional peer dependencies в npm 11, поэтому не использован. Точные версии зафиксированы в `package-lock.json`.

Нативную сборку необходимо проверить на физических iOS/Android с Expo Go, совместимым с SDK 58. Подключите телефон и компьютер к одной сети, задайте в `.env.local` адрес API, запустите `npx expo start --clear` и откройте QR-код. Проверьте вход, создание клиента и пакета, оплату, перенос, отмену, исправление и отзыв клиентской ссылки. Туннель Metro не открывает доступ к локальному API.

Проверка зависимостей от 24 октября 2026 года: `npm audit --omit=dev` обнаружил 5 high в транзитивном инструментарии Expo CLI (`node-forge@1.4.0` и CLI-копия Zod 3). Приложение использует Zod 4.6.7. На дату проверки совместимого исправления для выбранного SDK не найдено. Перед развёртыванием повторите аудит и проверьте обновления Expo.

Переключатель темы находится в общей шапке и доступен на экране входа, в кабинете и на публичной странице. Начальный режим соответствует системе; явный выбор хранится в localStorage браузера или SecureStore телефона отдельно от сессии.

Для телефона клиента предусмотрено отдельное необязательное поле. Допустимы `+7 (999) 123-45-67`, `8 999 123 45 67` и `9991234567`; сохраняется `+79991234567`. Формат проверяется и формой, и Go API, общий `contact` остаётся дополнительным способом связи.
